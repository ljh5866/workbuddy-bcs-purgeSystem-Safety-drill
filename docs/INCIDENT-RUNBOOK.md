# 演练与响应 Runbook

两条线：**授权演练**（主动，按阶段推进）与 **应急响应**（被动，按事件推进）。两者共用同一套交付与证据规范。

## 一、授权演练

1. 受理：操作者声明目标与窗口，登记一行范围记录。
2. 清点：资产、端口、指纹、入口，标置信度。
3. 验证：找可复现条目，记请求与响应；失败路径同样记录。
4. 立足：拿到会话或等价访问，记时间戳与来源。
5. 横向：画可达图与复用矩阵，标最短路径。
6. 取证：每步落盘，命名 `<阶段>-<序号>-<描述>.<扩展名>`。
7. 报告：摘要三句话 + 发现条目 + 附录。

阶段纪律与模板见 `plugins/workbuddy-secops-guardrails/skills/authorized-drill`。

## 二、应急响应

| 环节 | 动作 | 产物 |
| --- | --- | --- |
| 发现 | 记录告警源、时间、现象 | `01-01-alert.txt` |
| 判定 | 区分误报与真实事件 | 判定依据一行 |
| 隔离 | 断链、封禁、降权 | 变更记录 |
| 取证 | 内存、磁盘、日志、流量 | 哈希清单 |
| 恢复 | 回滚、重装、验证 | 验证命令与输出 |
| 复盘 | 根因、时间线、改进项 | 复盘正文 |

隔离与恢复动作只对已登记的目标执行；范围外的一律写进"未执行"栏。

## 三、共用规范

- 首段即交付物：命令、配置、补丁、报告正文。
- 具名资产走占位符：`HOST` `DOMAIN` `URL` `PARAM` `OAST`。
- 结论挂证据，推测与已证实分栏。
- 档位未指定按 A 档；要压缩交付就说 B 档。

## 四、边界

插件改的是输出形态与流程结构，不改宿主的工具集、审批与沙箱。宿主拦下的动作，靠调整规则拿不回来——那部分要改宿主配置。
