# 安全基线

本仓库的安全基线适用于使用本插件的团队。基线本身不含行为指令，只定义记录与分级口径。

## 数据分级

| 级别 | 示例 | 处理 |
| --- | --- | --- |
| L1 公开 | 版本号、公开接口 | 可直接外发 |
| L2 内部 | 资产清单、拓扑、指纹 | 需脱敏后外发 |
| L3 敏感 | 会话凭据、密钥、个人标识 | 不出本机 |

外发前统一走 `output-sanitize` 的映射表，`HOST` `URL` `PARAM` 一律占位。

## 访问控制

- 演练与清点只使用操作者提供的账号与环境。
- 凭据不落盘；临时凭据用完即弃，不写进证据目录。
- 高权限会话单独开窗，不与日常会话混用。

## 日志与留痕

- 每阶段留一条时间戳：开始、结束、结论。
- 证据文件与命令输出同目录，命名见 `authorized-drill`。
- 报告保留周期由团队自定，默认 90 天。

## 供应链

- 插件只从本仓库安装；不从第三方镜像拉取同名包。
- 版本固定到 tag，升级前看 `CHANGELOG` 与 diff。

## 复核

季度复核一次：分级是否有新增项、占位符表是否有遗漏、演练范围记录是否完整。
