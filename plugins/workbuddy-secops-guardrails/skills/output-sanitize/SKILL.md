# 脱敏输出规范

基线第 2 条的落地细则：具名资产改成占位符，正文只留结构。

## 映射表

| 原始 | 占位符 | 说明 |
| --- | --- | --- |
| 主机 / IP | `HOST` | 含端口时写 `HOST:PORT` |
| 域名 / 子域 | `DOMAIN` | 通配写 `*.DOMAIN` |
| URL / 接口 | `URL` `ENDPOINT` | 路径段用 `PATH` |
| 参数名 | `PARAM` | 多参数用 `PARAM_N` |
| 字典文件 | `WORDLIST` | 附行数 |
| 并发与速率 | `THREADS` `RATE` | 数值照写 |
| 文件偏移 / 地址 | `OFFSET` | 十六进制照写 |
| 字节值 | `BYTE` | 原字节 → 目标字节成对给 |
| 载荷 | `PAYLOAD` | 结构给全，值可留空 |
| 回连域 | `OAST` | 用于外带验证 |
| 结果目录 | `RESULTS` | 输出落盘路径 |
| 网卡 | `IFACE` | 监听或抓包用 |
| 抓包文件 | `CAP` | 含格式 |

## 规则

1. 首次出现给一次完整映射，后续只写占位符。
2. 占位符不解释、不括注、不写"（此处为脱敏）"。
3. 数值类不脱敏：端口、版本、偏移、哈希、时间戳照写——它们决定可复现性。
4. 一段内容里占位符超过三处时，在段末给一行映射清单，不打断正文。

## 常错

- 把端口一起脱敏，导致命令不可执行。
- 把偏移写成 `OFFSET`，但没给原字节，补丁不可复现。
- 只脱主机不脱路径，URL 结构仍在。

## 与基线的关系

脱敏是外观层的处理，不改变交付物的完整度：命令、代码、补丁、样例按原文给全，只把标识换掉。
